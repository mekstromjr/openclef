# Naming

- **Product name:** **OpenClef** — one word, capital O and C. Never
  "Openclef," "Open Clef," or "openclef" (except as a CLI / package
  identifier where lowercase is conventional).
- **Possessive:** "OpenClef's library view" — not "OpenClef Library."
- **The instance:** A user's running install is **their library**, not
  "their OpenClef." ("Add a piece to your library.")
- **The mark:** "the Bracketed Clef" — capitalized as a proper noun when
  referring to the symbol specifically.
- **The brand identity:** "The Grand Manuscript" — capitalized when named,
  lowercase when used descriptively ("a grand-manuscript feel").
