## Logo files

| Asset | Path | Formats | Notes |
| :--- | :--- | :--- | :--- |
| Primary lockup | `branding/logo/openclef-primary.{svg,png}` | SVG, PNG @1x/@2x/@3x | Default. |
| Inverted lockup | `branding/logo/openclef-inverted.{svg,png}` | SVG, PNG | Dark backgrounds. |
| Icon only | `branding/logo/openclef-icon.{svg,png,ico}` | SVG, PNG, ICO | Favicon, avatar. |
| Wordmark only | `branding/logo/openclef-wordmark.svg` | SVG | When icon already present nearby. |
| Monochrome — Charcoal | `branding/logo/openclef-mono-charcoal.svg` | SVG | Single-color print. |
| Monochrome — Ivory | `branding/logo/openclef-mono-ivory.svg` | SVG | Dark photo backgrounds. |

## Color swatches

| File | Format | Use |
| :--- | :--- | :--- |
| `branding/color/openclef.ase` | Adobe Swatch Exchange | Designers (Figma, Adobe). |
| `branding/color/openclef.clr` | macOS Color List | macOS-native apps. |
| `branding/color/tokens.css` | CSS custom properties | Frontend consumes this. |
