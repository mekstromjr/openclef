## Primary logo

The primary lockup is the **Bracketed Clef** symbol followed by the
**OpenClef** wordmark.

- **The Symbol** — a treble clef framed by two bold musical brackets, forming
  a stylized "O." It signals openness and the bracketed structure of musical
  systems simultaneously.
- **The Wordmark** — two fonts that mirror the brand's dual nature: a modern
  sans for "Open," a humanist serif for "Clef." See [Typography](./typography).

## Approved variants

| Variant | When to use |
| :--- | :--- |
| **Primary (full color)** | Default. Marketing site, README headers, light backgrounds. |
| **Inverted (Ivory on Charcoal)** | Dark UI, dark social cards, presentations on dark backgrounds. |
| **Monochrome — Charcoal** | Single-color print, faxes, embossed merch. |
| **Monochrome — Ivory** | Solid dark photographic backgrounds. |
| **Icon only (Bracketed Clef)** | Favicon, app icon, social avatars, small UI moments. |
| **Wordmark only** | When the icon is already shown nearby (e.g., page header next to the avatar). |

## Clear space & minimum size

- **Clear space:** at least the cap-height of the "O" on every side. Nothing —
  type, edges, photography — may enter that buffer.
- **Minimum size:**
  - Digital: full lockup ≥ 96 px wide; icon-only ≥ 24 px.
  - Print: full lockup ≥ 0.75 in wide; icon-only ≥ 0.25 in.
- **Favicon:** the icon-only mark must remain legible at 16×16 px. Ship a
  hand-tuned 16/32/48 raster favicon, not a downscaled SVG.

## Misuse

Don't:

- Recolor the mark outside the approved [palette](./color).
- Stretch, shear, or rotate the lockup.
- Add drop shadows, outer glows, or bevels.
- Place the full-color mark over busy photography — use a monochrome variant.
- Substitute the wordmark fonts. The lockup is a single image; type-setting
  "OpenClef" in arbitrary fonts is not a logo.
